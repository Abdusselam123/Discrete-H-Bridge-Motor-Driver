# Discrete-H-Bridge-Motor-Driver
This repository contains the design, LTspice simulations, and initial physical laboratory findings for a discrete component (transistor-based) H-Bridge motor driver. This project is maintained as a **living document** and will expand as the hardware undergoes further revisions.
